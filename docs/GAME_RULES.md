# Game Rules

This file is the authoritative gameplay rules document. Rules not written here are not considered locked.

## Locked foundation rules

**R001 — Commander selection**  
A player selects one Commander for a match.

**R002 — Army size**  
A player's equipped Army contains exactly four Army cards.

**R003 — Signature set**  
A Commander may reference a signature set containing four specific Army cards.

**R004 — Full-set activation**  
The Commander's signature set bonus activates only when all four required signature cards are equipped.

**R005 — Partial set**  
Equipping fewer than all four required signature cards does not activate the full-set Commander bonus.

**R006 — Starter elements**  
The foundation roster consists of Fire, Water, and Earth.

**R007 — Starter content size**  
The foundation data contains one placeholder Commander and four placeholder Army cards for each starter element.

**R008 — Initial opponent**  
The first playable prototype targets player-versus-AI, not online player-versus-player networking.

**R009 — Automatic combat direction**  
The intended match includes an automatic combat stage. Exact combat rules are design-pending.

**R010 — Drafting direction**  
The intended match includes drafting decisions. Exact draft rules are design-pending.

## Design-pending rules

The following must be decided before their respective systems are implemented:

- Commander base stats and direct combat participation
- Card roles and card statistics
- Exact set-bonus effects
- Draft pool and draft cadence
- Resource/cost system
- Unit placement and battlefield layout
- Targeting logic
- Damage formula
- elemental advantages/disadvantages, if any
- round structure, health/hearts, win/loss conditions
- comeback mechanics
- progression outside a match
