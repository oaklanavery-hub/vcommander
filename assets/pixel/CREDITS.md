# Detailed fantasy pixel artwork

Created for VCommander using the built-in image-generation tool on 17 October 2026. The user’s two supplied images are quality references for detailed pixel craft, silhouettes and sprite readability. No reference character or franchise asset is used in the game. These are original generated fantasy designs, replaceable with commissioned final artwork.

Project assets: `commanders-v2.png` (three 128×192 frames), `roster-v2.png` (thirteen 64×64 frames), mapped by `art_manifest.json`. Source PNGs were inspected, cropped, nearest-sampled and padded with ImageMagick through `tools/pack_pixel_art.py`; transparent alpha is retained. The original generation outputs remain outside the repository. Large generated images are not shipped in the Web build.

Commanders and units use one illustrated idle frame each. Movement, facing, attacks, hits and death remain procedural presentation, not a new set of hand-drawn animation frames. All rules and simulation stats are unchanged.
